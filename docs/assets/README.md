# Thesis figure sources and rights

The images in this directory are extracted **unchanged from embedded image streams** in the supplied bachelor thesis:

> Adrián Ibeas Lara, *Design of an Automated Vehicle Parking System Using a Microcontroller*, Bachelor in Telecommunication Technologies Engineering, academic year 2023–2024. Thesis supervisor: José Enrique Suárez Pascual.

The cover states **Creative Commons Attribution – Non Commercial – Non Derivatives**. It does not specify a license version, so no versioned license URL is assumed. This notice accompanies the reproduced thesis figures; it does not replace the vendor notices in the firmware or grant a repository-wide code license.

Only the author's project photographs and implementation diagrams are reproduced here. Third-party component photographs and illustrations are not included.
